# 課堂抽籤 · 密碼保護版

GitHub Pages版本，同事不需要ChatGPT或GitHub帳戶。開啟網站後，輸入教職員密碼即可使用。密碼不放在此儲存庫。

選好科目、年級和組別後，可使用一般抽籤、輪盤或Duck Race。三種模式共用本組抽籤進度；每次可抽1至10位，同一批不重複。輪盤依次抽選多人，Duck Race按衝線名次揭曉；輪盤、賽道、小鴨及姓名已放大，遊戲使用全行版面，設定及紀錄移至下方；賽程可選5、8、12或20秒，並可快速完成或關閉動畫。保留撤銷、開始新一輪及投影模式；中途鎖定不記錄未完成的抽籤。

揀好組別後，可按「＋ 加入新同學」，只需輸入名字，毋須班別或學號。新增同學只加入目前組別，與原有名單分開保存；不改動原有學生資料，亦不重設抽籤進度。新增名字以獨立AES-256-GCM密文保存在此瀏覽器，解鎖時以相同密碼讀取，不會上傳到GitHub或同步其他裝置；清除此瀏覽器資料後需重新加入。可在學生名單內移除自行新增的同學；開始新一輪仍會保留新增名單。

按原班抽籤新增：佛學及公經社（中一至中三），以及公民科（中四至中六）。現階段班名單暫以中文科現有名單按班別整理；中六公民則由本科原分組表按班彙整。介面會顯示班名單來源，未把不同科的名單混合補人或補號。原有145份分組資料、組別識別碼及抽籤進度保留；中六公民可選按原班或原有教學分組。

整個抽籤程式與學生名單以AES-256-GCM加密，使用PBKDF2-SHA256（600000次）從密碼衍生金鑰。儲存庫只包含解密入口、隨機salt／IV及密文，不包含明文學生名單、密碼或可直接使用的解密金鑰。解密後的內容只在瀏覽器內執行，使用後可按「鎖定」。

GitHub Pages是靜態主機，無伺服器端登入或防暴力破解。加密檔可被下載後離線猜密碼，密碼宜長而不易猜。已獲密碼並解鎖的人仍可複製或匯出名單，請只向獲授權教職員提供密碼。

網站不使用追蹤程式或外部字型。抽籤進度只保存在使用中的瀏覽器。原名單的學號及組名差異保留於解鎖後的「名單來源與備註」，未自行更改。

## 原班共用計分

多位老師可在不同電腦用同一教職員密碼進入。抽中同學後按「答啱＋1」，或開啟「原班計分」搜尋學生直接加分；分數以「學年＋科目＋原班」獨立長期累積；例如4A中文與4A英文互不影響，只有同科同班才共用。各科依網站科目選單分開（包括英文Core、Speaking及泛讀），其他電腦約每十五秒更新一次，亦可按「重新同步」。關閉網頁或清除此瀏覽器資料，不會清除已確認儲存的雲端分數。

可「撤銷最近加分」撤銷這部電腦最近一次加分。「本班分數清零」須再次確認，只清除所選科目及原班的累積分數，不影響其他科目、其他班或抽籤紀錄。不同老師同時加分以獨立紀錄累加，網絡重試不會重複計分。未連線時不可加分；若顯示儲存未確認，請恢復連線後重試同一次操作。

共用計分需連接網上版本。雲端服務只接收不可直接辨識姓名的班別及學生代碼、加分／撤銷／清零紀錄和時間，不接收學生姓名或名單；讀寫須通過教職員密碼驗證。登入憑證只存於目前頁面記憶體。雲端分數服務獨立於 GitHub Pages，由網站擁有人管理。

自行新增同學的名字仍只保存在原來瀏覽器。其他電腦若需顯示該同學的名字，須在同一原班加入完全相同的名字，便會對應相同分數。混合原班的教學分組抽中新同學時，先選一次計分原班；原有名單不需重複輸入班別。各科原表已有差異時，計分以現有按班底本對應，不改寫原始名單。

舊版未有記錄加分所屬科目，原有跨科分數不會猜測分配或複製到各科。可在計分科目選單的「舊版跨科紀錄（唯讀）」查看；新版各科分數獨立開始，舊紀錄完整保留。舊版頁面會拒絕再寫入跨科分數，請重新整理以使用新版。

資料更新時應在本機重新加密，再提交新的index.html；切勿提交未加密原始名單或舊的明文離線版。更換密碼後，已下載的舊加密版本不會自動失效。


## 同步與用量

GitHub Pages只發布加密網頁，日常加分、同步、撤銷及清零均直接連接獨立雲端資料庫，不會建立GitHub commit、GitHub API寫入或重新建置網站。GitHub Pages目前每小時10次建置及每月100GB流量均為軟上限，詳見官方：https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits 。

同步約每15秒進行；背景分頁、未選科目及班別時停止自動讀取，連線失敗逐步延至最多60秒重試。每次先查科班版本，有變動才下載分數；分數以索引總表增量更新，不會每次掃描整年加分紀錄。手動「重新同步」可立即更新。以30位老師每天使用6小時計，15秒輪詢約43,200次讀取請求，相比5秒的129,600次減少約67%（未計登入、加分及跨來源預檢）。

雲端仍有請求、讀寫及容量限制；目前Sites帳戶的實際額度未獲確認，不能把Cloudflare公開免費方案當成此帳戶的保證。加分事件及舊紀錄會長期保留，清零不會回收其歷史儲存空間；需按實際用量評估日後封存。官方參考：https://developers.cloudflare.com/workers/platform/limits/ 及 https://developers.cloudflare.com/d1/platform/pricing/ 。
